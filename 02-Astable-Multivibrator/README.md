# Astable Multivibrator PCB

A compact **Astable Multivibrator** circuit designed in **Autodesk EAGLE** using BC547 transistors to generate continuous oscillation and alternate LED blinking.

### Features

* BC547 transistor-based design
* Two alternating LED outputs
* Double-layer PCB
* Polygon copper pour
* Compact PCB layout
* Schematic and PCB design included

### Tools

* Autodesk EAGLE
